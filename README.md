# DSAI

This repository documents the work completed during my **Data Science & AI (DSAI) Internship Program**. It reflects a structured progression through the syllabus — starting from Python and NumPy fundamentals, moving into data analysis and visualization, and building up to feature engineering, NLP, and core machine learning algorithms applied to real-world-style datasets.


## 📚 What This Covers


### 🐍 Python & NumPy Fundamentals
Foundational exercises in Python programming and array-based computation using NumPy — covering array creation, indexing, slicing, reshaping, and vectorized operations that form the base for all later data science work.

- `numpy.ipynb` — NumPy practice: array operations, broadcasting, and numerical computations
- `array.ipynb` — Array manipulation exercises


### 📊 Data Analysis & Visualization
Exploratory Data Analysis (EDA) on real and sample datasets, using visualization libraries to identify trends, distributions, and relationships in data before modeling.

- `data.ipynb`, `data_graphs.ipynb` — Data cleaning, exploration, and graphical analysis
- `plotly.ipynb` — Interactive, dynamic visualizations (charts, plots) using Plotly
- `sales_data.ipynb`, `sales_dsd.ipynb`, `Sample - Superstore.csv` — Sales trend analysis on retail-style transactional data
- `customer_segmentation_100_records.csv` — Dataset used for grouping customers by behavior/attributes


### 🤖 Machine Learning Algorithms
Hands-on implementation of supervised and unsupervised ML algorithms, applied to sample datasets to understand model training, evaluation, and prediction.

- `knn.ipynb` — K-Nearest Neighbors classification, understanding distance-based prediction
- `svm.ipynb` — Support Vector Machines for classification tasks
- `cluster1.ipynb` — Unsupervised clustering (e.g., K-Means) to group unlabeled data
- `multilinear_salary.py`, `multiple_linear_salary_dataset_50_records.csv` — Multiple Linear Regression to predict salary based on multiple features (e.g. experience, education)
- `reg2.py`, `trainingtesting.ipynb` — Regression modeling with explicit train-test split workflows to evaluate model performance
- `feature_extraction.ipynb` — Techniques for selecting/engineering meaningful features from raw data to improve model accuracy


### 🏢 Applied ML Projects
Practical mini-projects applying ML concepts to structured business-style datasets, simulating real use cases like employee data analysis.

- `emp_ml.ipynb`, `employee_ml.py`, `Employee.csv.xls` — Predictive modeling on employee data (e.g. salary/performance prediction)
- `ML.ipynb`, `ml11.py` — Additional general-purpose ML practice and experimentation


### 🗣️ Natural Language Processing (NLP)
Introductory exploration of NLP concepts and libraries for processing and analyzing text data.

- `nlp_libraries.ipynb` — Hands-on practice with core NLP libraries (e.g. tokenization, text preprocessing basics)


### 💻 Mini Applications
Small standalone Python programs built to practice logic, functions, and basic application structure outside of notebooks — simulating simple real-world tools.

- `registrationform.py`, `userlogin.py` — Basic user registration/login system logic
- `profilecard.py` — Program to generate/display a formatted profile card
- `performancesys.py` — A simple performance tracking system
- `salaryrecords.py` — Program to manage and process salary record data


## 🛠️ Tech Stack
- **Language:** Python
- **Core Libraries:** NumPy, Pandas, Matplotlib, Plotly, Scikit-learn
- **Environment:** Jupyter Notebook

## 🎯 Purpose
This repository serves as a comprehensive record of my learning journey through the DSAI internship program — demonstrating practical, hands-on understanding of the full data science and machine learning workflow: from raw data handling and visualization, to feature engineering, model building, and evaluation.
